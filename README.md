# AI 기반 항공기 부품 생산계획·부하 분석 및 생산현안 관리 시스템

생산관리 실습에서 접한 **생산계획–부하 분석–진도/납기 관리 흐름**을 바탕으로, 컴퓨터공학 전공 역량을 결합해 만든 개인 프로젝트입니다.  
가상의 항공기 부품 생산 데이터를 분석하여 **과부하 공정, 생산현안, 후속 일정 영향, 최종 출하 현황**을 시각화하고 AI가 생산관리자의 확인사항과 대응 검토안을 제시하도록 구현했습니다.

> **중요:** 이 프로젝트는 실제 기업의 내부 데이터·표준공수·생산능력·판정 기준을 사용하지 않습니다. 모든 생산 데이터는 학습/포트폴리오 목적의 가상 데이터입니다.

## 핵심 기능

### 1. 대시보드 기반 전체 생산현황 요약

전체 생산 데이터를 기준으로 주요 KPI를 한 화면에서 확인할 수 있도록 구성했습니다.

- 전체 계획수량과 실제 생산수량을 기반으로 **전체 생산달성률** 계산
- 실제 생산수량 대비 불량수량을 기준으로 **전체 불량률** 산출
- 전체 공정의 계획완료일과 실제완료일을 비교하여 **계획일정 준수율** 계산
- 계획일정보다 실제 완료가 늦은 **일정 지연 항목 수** 집계
- 최종 출하 공정만 별도로 분리하여 **최종 출하 준수율, 출하 일정 준수 건수, 출하 일정 지연 건수** 확인

이를 통해 생산실적·품질·일정·최종 출하 상태를 대시보드 상단에서 빠르게 파악할 수 있도록 했습니다.


### 2. 부품별 생산공정 흐름 분석

특정 부품을 선택하여 가공부터 출하까지 전체 공정 흐름을 순서대로 분석할 수 있도록 구성했습니다.

- `가공 → 표면처리 → 조립 → 도장 → 검사 → 출하` 순서로 공정 데이터 정렬
- 각 공정의 **생산달성률, 불량률, 일정지연, 계획부하율** 확인
- 부품별 **최종 출하 생산달성률과 출하 지연 여부** 확인
- 특정 부품에서 **과부하 또는 일정 문제가 발생한 공정** 파악

이를 통해 개별 공정만 확인하는 것이 아니라 하나의 부품이 전체 생산공정을 거치는 과정에서 발생한 생산현안을 연속적으로 확인할 수 있도록 했습니다.


### 3. 부품별 AI 공정흐름 종합분석

선택한 부품의 전체 공정 데이터를 AI가 종합적으로 분석하도록 구현했습니다.

AI 분석에는 각 공정의 다음 데이터를 활용합니다.

- 계획수량 / 실제수량
- 생산달성률
- 불량수량 및 불량률
- 계획완료일 / 실제완료일
- 지연일수
- 계획 소요공수 / 가용공수
- 계획 부하율
- Bottleneck 검토 여부
- 후속공정 영향 여부
- 최종 출하 상태

AI는 이를 바탕으로 **주요 생산현안, 우선 확인 공정, 추가 확인사항 및 대응 검토안**을 제시합니다.

단, 설비고장·자재부족·작업자 문제 등 데이터에 존재하지 않는 원인을 사실로 단정하지 않도록 제한하고, AI는 생산관리자의 판단을 지원하며 **최종 의사결정은 생산관리자가 수행**하도록 설계했습니다.


### 4. 공정별 상세 생산정보 확인

선택한 부품의 공정별 주요 분석 결과를 표 형태로 확인할 수 있도록 구성했습니다.

- 생산달성률
- 불량률
- 일정 지연일수
- 계획 부하율
- 검토구분
- 다음 공정 정보
- 후속공정 일정 영향 여부

과부하, 일정지연, Bottleneck 검토 대상, 후속공정 영향 등 주요 항목을 시각적으로 강조하여 **우선 확인이 필요한 공정을 빠르게 파악**할 수 있도록 했습니다.


### 5. 후속공정 일정 영향 분석

앞 공정의 실제 완료시점이 다음 공정의 계획일정에 영향을 줄 가능성이 있는지 분석합니다.

각 부품의 공정 순서를 기준으로 **현재 공정의 실제완료일과 다음 공정의 계획일을 비교**하고, 앞 공정의 실제 완료가 다음 공정 계획시점보다 늦은 경우 후속 일정 영향 검토 대상으로 표시합니다.

이 기능은 공정 지연의 인과관계를 확정하는 것이 아니라, **앞 공정의 완료시점이 후속공정 계획에 영향을 줄 가능성이 있는 항목을 선별**하는 목적으로 구현했습니다.


### 6. 생산현황 요약 및 생산실적 시각화

전체 생산 데이터를 바탕으로 주요 생산현안을 요약하고, 부품 및 공정별 생산실적을 시각화했습니다.

- 계획수량보다 실제 생산수량이 적은 **계획 미달 항목 수** 집계
- 계획완료일보다 실제완료일이 늦은 **일정 지연 항목 수** 집계
- 불량수량이 발생한 **불량 발생 항목 수** 집계
- 부품별 **계획수량과 실제 생산수량 비교**를 통한 생산실적 시각화
- 공정별 **평균 생산달성률 비교**를 통한 상대적 생산실적 확인

생산현안의 발생 규모를 요약 지표로 확인하고, 부품별 계획 대비 실적과 공정별 평균 생산달성률을 그래프로 시각화하여 **전체 생산실적과 주요 관리 필요 항목을 직관적으로 파악**할 수 있도록 했습니다.


### 7. 생산 부하 및 공수 분석

생산계획 수행에 필요한 공수와 실제 가용공수를 비교하여 생산능력의 과부하 여부를 분석합니다.

**계획 소요공수**

`계획 소요공수 = 계획수량 × 단위 표준공수`

예를 들어 계획수량이 110개이고 단위 표준공수가 0.105h/개라면 계획 소요공수는 **11.55h**입니다.

**계획 부하율**

`계획 부하율 = 계획 소요공수 ÷ 가용공수 × 100`

계획 소요공수가 가용공수보다 큰 경우 **계획상 과부하**로 식별합니다.

또한 전체 데이터를 기준으로 다음 지표를 집계합니다.

- 과부하 항목 수
- 최대 계획 부하율
- 총 부족공수

이를 통해 생산계획 대비 **가용 생산능력이 부족한 공정과 부족 규모**를 확인할 수 있도록 했습니다.


### 8. 부품 × 공정 부하 Heatmap

계획 부하율을 부품과 공정 단위로 시각화하여 **부하가 집중된 위치를 빠르게 확인**할 수 있도록 구성했습니다.

- 세로축: 부품
- 가로축: 공정
- 각 셀: 해당 부품·공정의 계획 부하율

계획 소요공수가 가용공수를 초과한 항목을 별도로 강조하여 **어떤 부품의 어떤 공정에서 계획상 과부하가 발생했는지 직관적으로 확인**할 수 있도록 했습니다.


### 9. Bottleneck 및 생산현안 검토

계획상 과부하와 실제 생산 결과를 함께 고려하여 생산관리자가 우선적으로 검토할 공정을 식별합니다.

본 프로젝트에서는 Bottleneck을 단순히 높은 부하율만으로 확정하지 않고 다음 조건을 활용합니다.

`계획상 과부하 + (생산실적 미달 또는 일정지연)`

해당 조건을 만족하는 공정을 **Bottleneck 검토 대상**으로 분류합니다.

이를 통해 계획 단계에서 가용 생산능력을 초과했고 실제 생산 과정에서도 실적 또는 일정 문제가 나타난 공정을 우선적으로 확인할 수 있습니다.

단, 이를 실제 Bottleneck의 원인으로 확정하지 않으며 **생산관리자가 우선 검토할 항목을 선별하는 의사결정 지원 기능**으로 활용합니다.


### 10. 생산현안 상세분석

생산현안으로 식별된 항목을 선택하여 해당 공정의 주요 지표를 상세하게 확인할 수 있도록 구성했습니다.

- 계획수량 대비 실제수량
- 생산달성률
- 불량수량 및 불량률
- 일정 지연
- 계획 소요공수
- 가용공수
- 계획 부하율
- 부족공수
- 후속공정 일정 영향

이를 통해 생산현안이 발생한 항목에서 **어떤 지표에 문제가 나타났는지 구체적으로 확인**할 수 있도록 했습니다.


### 11. AI 생산현안 분석

선택한 생산현안의 실적·품질·일정·부하 데이터를 AI가 종합적으로 분석하여 생산관리자의 현안 검토를 지원합니다.

AI는 입력된 데이터를 바탕으로 다음 내용을 제시합니다.

- 현재 데이터에서 확인되는 주요 생산현안
- 과부하 및 생산실적·일정 상태
- 우선적으로 확인할 사항
- 추가 확인이 필요한 잠재적 원인
- 생산계획 및 가용공수 조정 등의 대응 검토안

AI가 데이터에 존재하지 않는 원인을 사실로 단정하지 않도록 제한하고, **생산관리자를 대체하는 것이 아니라 데이터 해석과 의사결정을 지원하는 보조 도구**로 활용했습니다.


### 12. 전체 생산 데이터 조회

분석에 사용된 전체 가상 생산 데이터를 확인할 수 있도록 구성했습니다.

대시보드의 KPI, 생산실적, 부하 분석 및 생산현안 결과가 **어떤 원본 데이터를 기반으로 산출되었는지 직접 확인**할 수 있도록 하여 분석 결과의 추적성과 확인 가능성을 높였습니다.

## 분석 흐름

```text
가상 생산계획
    ↓
계획수량 × 단위 표준공수
    ↓
계획 소요공수
    ↓
가용공수 비교
    ↓
계획 부하율 / 부족공수
    ↓
과부하 및 Bottleneck 검토
    ↓
생산실적 · 품질 · 일정 확인
    ↓
후속 공정 일정 영향 검토
    ↓
최종 출하 현황
    ↓
AI 확인사항 / 대응 검토안
    ↓
생산관리자 최종 판단
```

## 주요 계산식

| 지표 | 계산식 |
|---|---|
| 생산달성률 | 실제 생산수량 ÷ 계획 생산수량 × 100 |
| 불량률 | 불량수량 ÷ 실제 생산수량 × 100 |
| 계획 소요공수 | 계획수량 × 단위 표준공수 |
| 계획 부하율 | 계획 소요공수 ÷ 가용공수 × 100 |
| 부족공수 | max(계획 소요공수 - 가용공수, 0) |
| 계획일정 준수율 | 계획일까지 완료된 전체 공정 수 ÷ 전체 공정 수 × 100 |
| 최종 출하 준수율 | 출하 계획일까지 완료된 출하 항목 수 ÷ 전체 출하 항목 수 × 100 |

### 과부하 판정

별도의 임의 위험등급을 두지 않고,

```text
계획 소요공수 > 가용공수
```

인 경우에만 `과부하`로 표시합니다. 즉 부하율 100% 초과는 별도의 기업 위험기준이 아니라 **필요 공수가 가용능력을 초과했다는 계산 결과**입니다.

### Bottleneck 검토

본 프로젝트는 특정 공정을 Bottleneck으로 자동 확정하지 않습니다.  
계획 단계의 가용능력 초과와 실제 생산 미달 또는 일정 지연이 함께 나타나는 항목을 **`Bottleneck 검토 대상`**으로 표시하여 생산관리자의 확인 우선순위를 지원합니다.

## AI 분석 원칙

AI는 원인을 자동 확정하는 도구가 아니라 **생산관리 의사결정 지원 도구**로 사용합니다.

- 데이터에 없는 설비 고장, 자재 부족, 재작업, 작업자 문제 등을 발생 사실로 단정하지 않음
- 과부하와 실적 저하가 함께 보여도 직접적인 인과관계를 확정하지 않음
- 가능한 원인과 우선 확인사항을 구분해서 제시
- 생산계획 조정, 가용공수 확보, 우선순위 조정, 후속 일정 재검토 등을 **검토안**으로 제시
- 최종 판단은 생산관리자가 수행

## 기술 스택

- **Python** — 생산 데이터 분석 및 업무 로직 구현
- **pandas** — 생산실적·일정·공수 데이터 가공 및 KPI 산출
- **Streamlit** — 생산관리 대시보드 구현
- **Altair** — 생산실적 및 부하 분석 시각화
- **Excel (.xlsx) / openpyxl** — 가상 생산 데이터 저장 및 입출력
- **OpenAI API** — 생산현안 및 공정흐름 AI 분석

## 실행 방법

### 1. 저장소 Clone

```bash
git clone <YOUR_REPOSITORY_URL>
cd kai-production-ai
```

### 2. 가상환경 생성

Windows:

```bash
python -m venv venv
venv\Scripts\activate
```

macOS / Linux:

```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. 패키지 설치

```bash
pip install -r requirements.txt
```

### 4. API Key 설정

AI 분석 기능을 사용하려면 사용자가 발급받은 OpenAI API Key가 필요합니다.
프로젝트 루트에 .env 파일을 생성한 후 본인의 API Key를 설정합니다.
API Key가 없는 경우 AI 분석을 제외한 데이터 분석 및 시각화 기능을 사용할 수 있습니다.

```text
OPENAI_API_KEY=your_api_key_here
```


### 5. 실행

```bash
streamlit run app.py
```
