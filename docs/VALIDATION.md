## 반올림 원칙

중간 계산값은 가능한 한 원본 정밀도를 유지하고, 화면 출력 시 자릿수를 통일합니다.

- 비율: 소수점 첫째 자리
- 공수: 소수점 둘째 자리
- 단위 표준공수: 소수점 셋째 자리
- 수량/지연일수: 정수
